# Stone Age

A C implementation of the Stone Age board game with an SDL2 interface, made for the Programming Techniques (PT) course.

## Build

Requires `gcc`, SDL2 and SDL2_ttf.

```bash
make          # builds ./stone_age
make tests    # builds and runs the test suite
make clean
```

## Run

```bash
./stone_age
```

See `regulations.txt` for a summary of the game rules.
